# Review protocol

## Unit and eligibility

The unit is an evaluated configuration: one source-reported endpoint under one materially distinct evaluation setting with a full-text anchor. The publication cutoff is 26 July 2026. Version-of-record sources supersede earlier versions; retained records must support the evidence map and have a persistent identifier.

## Evidence

Evaluated configurations use named full-text sections and stable page ranges where available; HTML-first sources use `HTML n.p.`. The evidence ledger records source location, link, verification date, supported claim, and claim boundary.

## Coding and recoding

O, E, and A use endpoint precedence. C1-C3 and N1-N3 are compositional; C0 and N0 are exclusive baselines. Physics insertion is coded separately.

A02 and A03 each contain two fixed configuration slots for every retained study. Filled slots determine configuration presence and count. Presence/count agreement uses the full retained corpus. O/C/E/A/N, physics insertion, and claim-boundary reliability uses studies with the same positive count and identical fixed-slot alignment. Confidence intervals use study-cluster bootstrap resampling.
